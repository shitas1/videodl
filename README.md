# Скачиватель видео для Android: как собрать APK

Собирать ничего на компьютере не нужно: APK собирает бесплатный GitHub Actions.

## Шаги

1. Зарегистрируйтесь на github.com (бесплатно).
2. Нажмите **+ → New repository**, назовите `videodl`, выберите **Public**, нажмите **Create repository**.
3. В репозитории: **Add file → Upload files**, загрузите `main.py` и `buildozer.spec`, нажмите **Commit changes**.
4. **Add file → Create new file**. В поле имени введите `.github/workflows/build.yml` (слэши создадут папки сами). Вставьте содержимое файла `build.yml` из этого архива и нажмите **Commit changes**.
5. Откройте вкладку **Actions**. Сборка стартует сама (первая занимает 20-40 минут). Если не стартовала: выберите **Build APK → Run workflow**.
6. Когда появится зелёная галочка, откройте запуск и внизу в разделе **Artifacts** скачайте `video-downloader-apk`. Внутри zip лежит `.apk`.
7. Перенесите APK на телефон и откройте его. Разрешите установку из неизвестных источников. Play Protect может предупредить о неизвестном приложении: для своей сборки это нормально.
8. При первом запуске разрешите доступ к файлам.

## Если сборка упала (красный крест)

Откройте запуск, шаг **Build with Buildozer**, скопируйте последние 40 строк лога и пришлите их, я разберу ошибку.

## Особенности Android-версии

- Без ffmpeg скачивается готовый файл с видео и звуком. Если сайт отдаёт видео и звук раздельно (бывает на Reddit и YouTube в высоком качестве), качество может быть ниже или звука не будет.
- Аудио сохраняется в исходном формате (m4a, mp3, opus), без конвертации в MP3.
- Альбомы и плейлисты SoundCloud скачиваются целиком: ссылка вида `soundcloud.com/автор/sets/альбом` определяется сама, для остальных сайтов включите галочку «Альбом / плейлист целиком». Треки сохраняются в папку с названием альбома, с номерами.
- SoundCloud работает для публичных треков. Spotify и Apple Music не поддерживаются: они защищены DRM.
- Если файлы не сохраняются в Download, в Настройках выберите папку Movies/VideoDownloader или оставьте папку приложения: приложение само переключится на неё, если запись запрещена.
- Если сайт перестал работать, обновите yt-dlp: перезапустите сборку (она берёт свежую версию).
